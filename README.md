# us-traffic-ticket-statutes-2026

Open-source 51-jurisdiction U.S. speeding ticket DMV points, 3-year insurance surcharges, and written declaration statutes dataset (MIT).

## Live Interactive Workbench & Calculators

- **Official Platform**: [TicketFig](https://ticketfig.com/)
- **4-Step Guided Statutory Wizard**: [https://ticketfig.com/wizard/](https://ticketfig.com/wizard/)
- **Free Embeddable Calculator Widget**: [https://ticketfig.com/embed/](https://ticketfig.com/embed/)

## Dataset

See `data/statutes.ts` for the full 51-jurisdiction (50 U.S. States + D.C.) statutory matrix maintained by [TicketFig](https://ticketfig.com/).
